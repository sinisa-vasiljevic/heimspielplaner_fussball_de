Heimspielplaner 50.12 - sicherer Synchronisationsablauf

Änderungen:
- Ein unvollständiger FUSSBALL.DE-Abruf darf kein bereits bekanntes Spiel löschen.
- Python führt neuen Abruf und alten spiele-live.json-Bestand zusammen.
- Die App führt frische Daten mit ihrem lokalen Cache zusammen, statt den Cache komplett zu ersetzen.
- Der Workflow prüft vor Commit/Deployment, dass keine vorhandene Spiel-ID fehlt.
- Der Workflow führt vor dem Push git pull --rebase aus, damit parallele Updates von manuelle-spiele.json nicht zum non-fast-forward-Abbruch führen.
- Erst der erfolgreich geprüfte und gepushte Stand wird auf GitHub Pages veröffentlicht.

- .github/workflows/sync-spiele.yml
